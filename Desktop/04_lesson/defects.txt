# Отчет о дефектах (Defects Report)
# Проект: Утилита обработки строк (StringUtils)
# Дата: 19.07.2026

## Дефект #1: Метод `capitalize` не обрабатывает пустую строку
- **Описание**: При передаче пустой строки `""` метод вызывает исключение `IndexError: string index out of range`, так как пытается обратиться к `text[0]`.
- **Шаги для воспроизведения**: Вызвать `StringUtils.capitalize("")`.
- **Ожидаемый результат**: Возврат пустой строки `""` без исключений.
- **Фактический результат**: Падение с `IndexError`.
- **Приоритет**: Высокий (High).

## Дефект #2: Методы класса не обрабатывают входное значение `None`
- **Описание**: При передаче `None` в методы `capitalize`, `reverse`, `is_palindrome` и `count_words` возникает исключение `TypeError` или `AttributeError`, так как код пытается вызвать строковые методы у объекта `NoneType`.
- **Шаги для воспроизведения**: Вызвать `StringUtils.is_palindrome(None)`.
- **Ожидаемый результат**: Возврат `False` (для `is_palindrome`), `0` (для `count_words`) или явное исключение `ValueError` с понятным сообщением.
- **Фактический результат**: Падение с `AttributeError` или `TypeError`.
- **Приоритет**: Средний (Medium).

## Дефект #3: Метод `count_words` некорректно считает слова при множественных пробелах
- **Описание**: Метод использует `text.split(" ")`, что приводит к созданию пустых строк в списке при наличии нескольких пробелов подряд. Например, для строки `"  "` (два пробела) метод вернет `3`, хотя слов там нет.
- **Шаги для воспроизведения**: Вызвать `StringUtils.count_words("  ")`.
- **Ожидаемый результат**: `0`.
- **Фактический результат**: `3`.
- **Приоритет**: Высокий (High).
- **Рекомендация по исправлению**: Использовать `text.split()` без аргументов, что автоматически обрабатывает любые пробельные символы.
